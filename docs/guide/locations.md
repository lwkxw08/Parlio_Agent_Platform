## Your locations

Add a location for each branch or brand. Fields: **Location name** (your label), **Answers as (brand name)** — what the assistant says when calls to this location's numbers arrive, **Phone numbers for this location** (one per line; calls to these numbers are tagged with the location), **Address** (read to callers when they ask), **Timezone**, and which **Assistant** answers.

Transfer destinations can be tied to a location on the *Transfers* page so a caller to the Leeds number reaches the Leeds team. Analytics, Calls and Tickets can all be filtered by location.

## Roll-up

Totals across all locations for the period: calls, answered rate, transfers, tickets and bookings per location, side by side, so you can see which branch is busiest or missing calls.
